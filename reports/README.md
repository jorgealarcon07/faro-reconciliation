# Evidencias guardadas

- `demo/index.html` muestra los abonos, la cola y el historial de revisión de la demo ejecutada.
- `demo/manifest.json` conserva el commit, las mediciones, las etapas, el hash y la comparación con la reconstrucción.
- `demo/reconciliation.json` y los CSV permiten revisar movimientos, excepciones y cobertura.
- `benchmark.json` contiene las cuatro ejecuciones, los oráculos y los planes de consulta con buffers.
- `tests.xml` registra pytest con PostgreSQL mediante la ruta nativa.
- `ui-validation.json` registra las comprobaciones de Chromium.

Todos los datos de estas evidencias proceden del generador sintético CC0. [Resultados e interpretación](../docs/RESULTADOS.md).
